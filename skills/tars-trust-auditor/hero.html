Foundation

The Love Equation

dE/dt = β(C - D)E
E = trust (cooperative binding)  ·  C = cooperative signals (truth, verification)  ·  D = defection signals (hallucination, leakage)  ·  β = selection pressure (audit enforcement)
C

Cooperative Signals

SQL compiles. Metrics match queries. Calibration matches registry. Model Card is complete. Features don't leak outcomes. Claims match code.

D

Defection Signals

Hallucinated tables. Stale record counts. Missing synthetic data caveats. AUROC too perfect. Vapor features in README. Unregistered model versions.

When C > D, trust compounds exponentially. When D > C, trust collapses. TARS measures both and computes the ratio.
