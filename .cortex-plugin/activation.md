# CoCo Platform Plugin

When this plugin is inactive, you can re-enable it by saying:

- "Enable the CoCo platform plugin"
- "I need TARS, SDLC, and The Bond"
- "Load the platform engineering tools"

This plugin provides: TARS trust auditor, SDLC preflight, GUPPI command center, The Bond shared cognition, synthetic data generation, agent guardrails, and enterprise pipeline governance.

To enable: `/plugin enable coco-platform`
